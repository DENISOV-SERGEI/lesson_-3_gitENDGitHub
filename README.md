# Telegram Content Bot (vpv04-<твоя_фамилия>-<твоё_имя>)

### 1) Что это
Это простой Telegram-бот на Python, созданный в качестве учебного мини-проекта. Бот принимает текстовые запросы от пользователя и имитирует генерацию ответов с помощью нейросетей.

### 2) Как запустить
1. Склонируйте репозиторий: `git clone https://github.com<твой_username>/vpv04-<твоя_фамилия>-<твоё_имя>.git`
2. Перейдите в папку проекта: `cd vpv04-<твоя_фамилия>-<твоё_имя>`
3. Установите зависимости: `pip install -r requirements.txt` (если используются внешние библиотеки)
4. Запустите бота: `python src/main.py`

### 3) Как проверить, что работает
После запуска скрипта введите в терминале команду для проверки локального метода или отправьте боту в Telegram команду `/start`. 
* **Пример команды в консоли:** `python src/main.py --test`
* **Ожидаемый результат:** В консоли отобразится сообщение `[Тест]: Бот успешно запущен и готов к работе!`
